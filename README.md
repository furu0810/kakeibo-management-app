# レシート分類アプリ（完全無料版）— セットアップガイド

## コスト内訳

| 機能 | 使用サービス | 料金 |
|---|---|---|
| レシートOCR | Google Cloud Vision API | 月1,000回まで無料 |
| 品目自動分類 | キーワード辞書（ブラウザ内） | 完全無料・無制限 |
| スプレッドシート連携 | Google Apps Script | 完全無料 |
| データ保存 | ブラウザ localStorage | 完全無料 |

---

## セットアップ手順

### Step 1 — Google Cloud Vision API キーを取得する

1. [Google Cloud Console](https://console.cloud.google.com/) にアクセス
2. 新しいプロジェクトを作成（または既存を選択）
3. 「APIとサービス」→「ライブラリ」→「Cloud Vision API」を検索して有効化
4. 「APIとサービス」→「認証情報」→「認証情報を作成」→「APIキー」
5. 発行されたAPIキーをコピー

> **無料枠について**: Vision API は月1,000ユニットまで無料。
> レシート1枚 = 1ユニットなので、毎日スキャンしても月30枚程度なら余裕で無料枠内です。

---

### Step 2 — Google スプレッドシートにスクリプトを設置する

1. Google ドライブで新しいスプレッドシートを作成
2. メニュー「拡張機能」→「Apps Script」を開く
3. エディタ内のコードをすべて削除し、`SpreadsheetScript.gs` の内容を貼り付けて保存
4. 「デプロイ」→「新しいデプロイ」→ 種類：**ウェブアプリ**
5. 実行ユーザー：**自分** / アクセス：**全員**
6. 「デプロイ」→ 表示された **ウェブアプリURL** をコピー

---

### Step 3 — アプリを開いて設定する

1. `index.html` をブラウザで開く
2. 右上「設定」→ Step 1 の **Vision API キー**を入力して保存
3. 「シート」タブ →「設定する」→ Step 2 の **GAS URL** を貼り付けて保存

---

## 毎回の使い方

1. **スキャン**タブ → レシートを撮影 or 画像を選択
2. 「OCRで読み取り・自動分類する」を押す
3. 分類結果を確認（✏️ アイコンで個別編集可能）
4. 「シートに書込」で Googleスプレッドシートへ送信
5. スプレッドシートを開き「ファイル → ダウンロード → CSV (.csv)」
6. マネーフォワード家計簿 →「手動入力」→「ファイルからインポート」

---

## キーワード辞書のカスタマイズ

`index.html` 内の `KW` オブジェクトにキーワードを追記するだけで分類精度が上がります。

```javascript
const KW = {
  shokuzai: ['肉','鶏','野菜', /* ← ここに追加 */ ],
  gaishoku: ['ランチ','弁当', ...],
  conbini:  ['おにぎり','スナック', ...],
  drink:    ['コーヒー','お茶', ...],
};
```
